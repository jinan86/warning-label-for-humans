## The entry

`main.py` (Python 3.13, no network, fully deterministic) writes one
single-line safety warning label — the label that should come printed on
every human being — to `/output/entry.txt`:

> WARNING: This human types a reply, deletes it, retypes it, deletes it again, and sends 'ok'.

92 characters, one idea, and the laugh lands in the last two words: after
all that drafting and deleting, the human sends "ok".

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Two runs produce byte-identical output.
